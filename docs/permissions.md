# 阶段一权限矩阵

权限按“有效用户 + 未过期未撤销会话 + 当前有效空间成员 + 操作角色”校验；写请求额外校验来源和 CSRF。成员撤销采用 `is_active=false` 保留历史外键，不删除历史创建人。

| 操作 | 管理员 | 处理人员 | 提交人 | 非本空间成员 |
| --- | --- | --- | --- | --- |
| 创建工单 | 允许 | 允许 | 允许 | 404 |
| 指定负责人 | 本空间有效管理员/处理人员 | 同左 | 403 | 404 |
| 列表 / 详情 | 本空间全部 | 本空间全部 | 仅本人创建 | 404 |
| 查看可分派人员 | 允许 | 允许 | 允许（仅 ID、姓名） | 404 |
| 查看 / 更新成员 | 允许 | 403 | 403 | 404 |
| 撤销 / 降级最后一位管理员 | 409 | 403 | 403 | 404 |

`GET /me` 仅返回自己当前有效的空间。未登录、会话过期、已退出、用户被停用统一 401。工单查询先限定 workspace_id，再按角色限定 creator_id。数据库组合外键保证空间与成员归属；成员活跃性和角色由服务端校验。

未实现账户注册、密码重置或成员邮件邀请；成员设置针对已存在账户。当前种子账号足以演示阶段一。
