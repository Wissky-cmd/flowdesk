# FlowDesk 界面设计与验收

日期：2026-10-04（Asia/Shanghai）。以 Awwwards、Webby Awards、FWA 的设计完成度作为目标，未参加评奖，不声称获得评审认可。

## 设计方向

“In the flow”：深墨绿导航、暖纸白工作区、青柠色选中态，配合原创参数化 SVG 流线。业务操作仍以中文为主，英文只作为品牌辅助层。图形和图标由仓库内 SVG / CSS 实现，无远程字体、图库图片或新增动画依赖。

## 自检与迭代

| 维度 | 完成与复核 |
| --- | --- |
| 排版 | 统一标题、正文、编号与元信息层级；工单标题增至桌面 14px；移动端长标题自然折行；组件分页、弹窗等提示统一中文 |
| 留白 | 工作区最大宽度、统一页面边距、明确章节间距；表单以主编辑区和辅助说明分栏；手机收为单列 |
| 视觉层级 | 主视觉明确“创建工单”入口；导航当前项、列表分栏、状态和优先级区分；数据使用真实 API，不添加虚构指标 |
| 色彩 | 复验 9 处主要文字；标题 8.50:1、编号 4.78:1、日期 4.94:1、状态 4.87:1、高优先级 5.48:1、主视觉说明 5.01:1、搜索输入 8.42:1、列表脚注 4.77:1、导航说明 5.63:1。抽样结果见 contrast.json；不是全站无障碍认证 |
| 动效 | 路由淡入、短距离位移、列表错峰出现、SVG 进入、刷新旋转；悬停和按下反馈；支持 prefers-reduced-motion，减少动画规则经代码检查，未切换系统设置实测 |
| 微交互 | 当前页标题/编号搜索、清空和空结果、优先级筛选、更新时间排序、列表/卡片切换、刷新同步提示、表单提交 loading；取消固定返回工单列表 |
| 键盘 | 跳到主要内容、可见焦点；移动导航焦点循环、Esc 关闭并回焦、背景 inert、滚动锁；图标按钮有中文名称，装饰 SVG 对辅助技术隐藏 |
| 响应式 | 320、390、768、1280、1440、1920px 六档工单页实测无横向溢出；390px 下工单及成员列表卡片化，表单和详情单列；平板主视觉标签碰线已修正 |
| 原创性 | FlowDesk 自有 f. 字标、参数化流线、章节序号、衬线品牌短句与统一图标，不复制具体获奖站点 |

三轮改进：第一轮建立系统与页面；第二轮修复移动换行、成员列表、导航焦点及路由滚动；第三轮修复辅助文字对比度、平板主视觉边界与中文组件提示。

- 桌面列表和卡片切换、搜索无结果、清除筛选、优先级“高”筛出对应工单、刷新回到已同步。

## 证据与边界

`docs/evidence/design/` 保存桌面/手机截图、`responsive.json`、`contrast.json`、`typecheck.txt`、`build.txt`。截图来自真实数据；部分截图是迭代中途记录，桌面最终主视图为 `tickets-desktop.jpg`。

目前主要页面与已操作状态未发现阻断使用的视觉问题。没有宣称审美上绝对不存在提升空间；Safari、Firefox、触屏真机、屏幕阅读器、Lighthouse、弱网行为与全站 WCAG 审计尚未验证。已有 reduced-motion 样式，未进行系统设置切换验证。

搜索、优先级筛选和排序仅作用于当前 API 分页内数据，界面已明确标注“当前页”；没有把它们当作后端全量筛选完成。阶段二业务功能仍按原计划推进。

## 关键源码

- `frontend/src/style.css`：设计变量、布局、响应式与减少动效规则。
- `frontend/src/components/FlowArt.vue`：原创 SVG 流线；`Icon.vue`：统一 SVG 图标。
- `frontend/src/App.vue`：响应式导航、焦点管理、中文配置和帮助弹窗。
- `frontend/src/views/Tickets.vue`：当前页检索、筛选、排序、视图和反馈状态。
- `frontend/src/views/Members.vue`：响应式成员卡片及编辑入口。
- `frontend/src/main.ts`、`router.ts`：按需组件样式和页面加载。
